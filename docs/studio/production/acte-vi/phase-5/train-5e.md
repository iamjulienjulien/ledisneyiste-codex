# Acte VI · Phase 5 · Train 5E

> **Document interne de production**<br>
> Établi par **🔩 R2-D2**, Lead Developer chez **Guru Éditions**.

## Mission

Le Train 5E rend un verdict R2 sur les vingt-deux Personnages du manifeste.
Il documente les formes originales réellement manquantes, confirme les
identités déjà conformes et préserve les noms invariants sans fabriquer de
doublon. Les vingt-deux routes historiques demeurent indépendantes de la
langue projetée.

## Corpus de provenance

Les portraits français de Chronique Disney documentent ensemble le nom
français et le nom original d’Oswald, Pat Hibulaire et Dingo. Les sources déjà
présentes — D23, Disney France, AFI et Library of Congress — suffisent à
contrôler les personnages dont les formes étaient déjà enregistrées.

La provenance n’est pas transformée en mutation automatique. Lorsqu’un nom
anglais et un nom français sont identiques, le Train conserve une seule forme
principale. Lorsqu’une forme originale est déjà sourcée dans la fiche, le
verdict ferme le raccord sans réécrire l’Archive.

## Trois raccords documentaires

- **Oswald le lapin chanceux** reçoit _Oswald the Lucky Rabbit_ comme forme
  originale anglaise.
- **Pat Hibulaire** reçoit _Peg-Leg Pete_ comme forme originale et _Pete_
  comme alias anglais. Le Train ne réduit pas la forme historique à l’alias
  contemporain.
- **Dingo** reçoit _Goofy_ comme forme originale anglaise. Les noms
  historiques _Dippy Dawg_ et _The Goof_ restent hors du contrat tant qu’un
  besoin éditorial ne justifie pas leur projection.

## Les invariants conservés

Mickey Mouse, Minnie Mouse, Clarabelle Cow, Horace Horsecollar, Donald Duck,
Daisy Duck et Pluto portent déjà la même forme dans les deux langues. Leur
ajouter un nom alternatif identique créerait une collision normalisée sans
information supplémentaire.

Les douze personnages de _Blanche-Neige et les Sept Nains_ possèdent déjà
leurs formes originales. Les deux exceptions témoins sont maintenues :
_The Evil Queen_ reste un alias distinct de _The Queen_ et _Humbert_ conserve
volontairement l’absence de langue documentée par la fixture de Phase 3.

## Ce que le Train ne fabrique pas

- aucun nom original n’est déduit d’une traduction littérale ;
- aucun alias historique supplémentaire n’est ajouté pour densifier une fiche ;
- aucun slug ni chemin n’est localisé ;
- aucune relation inverse n’est recopiée dans une fiche ;
- aucune matière _Pinocchio_ n’entre dans les Personnages existants ;
- aucun nom invariant n’est dupliqué dans `nomsAlternatifs`.
